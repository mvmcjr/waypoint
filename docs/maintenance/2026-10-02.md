## Release-note highlights

### TypeScript 6.0.3 → 7.0.2
- Native (Go) compiler. `tsc` is still the CLI and ships a platform binary via optional deps. Type-checking is much faster and runs in parallel (`--checkers`, `--builders`).
- Our configs typecheck clean with no edits; removed options (`baseUrl`, `node10` resolution, ES5 target, …) weren't in use.
- 7.0 has **no programmatic API** (it comes in 7.1). Nothing we use needs it. If typescript-eslint or similar is added later, alias `@typescript/typescript6` for it.

### Vitest 4 → 5
- `clearMocks` now defaults to `true`; our tests already clear mocks in `beforeEach`, so nothing changed.
- `vi.mock` must be at top level, `.resolves`/`.rejects` must be awaited, and `$var` in `test.each` titles is no longer quoted. We were already compliant.
- Fake timers now also mock `Temporal`.

### jsdom 29 → 30, jest-dom 6 → 7
- Node engine floors only (jsdom: `^22.22.2 || ^24.15 || >=26`; jest-dom: ≥ 22), and jest-dom now requires `@testing-library/dom` as a peer (we have it).
- jsdom 30: `getComputedStyle` normalises lengths to px; focus/blur fixes; undici 8.
- Worth adopting later: jest-dom `toContainAnyBy*` / `toContainOneBy*` matchers.

### git2 0.20 → 0.21
- `ssh`, `https`, `cred` features are no longer default. We do no in-process networking (remote ops shell out to system `git`), so this removes OpenSSL and libssh2 from the build.
- The explicit `openssl = { features = ["vendored"] }` line was only there so OpenSSL compiled for macOS universal builds. `cargo tree -i openssl-sys --target all` showed nothing else needed it, so it was removed.
- String accessors (`Commit::summary/body/message`, `Reference::name/shorthand/symbolic_target`, `Signature::name/email`, `Remote::url`, `StatusEntry::path`, `StringArray::iter`) now return `Result`. About 30 call sites were migrated with `.ok()` / `.ok().flatten()`, so non-UTF-8 is still treated as missing, exactly as before.
- Worth adopting later: `Repository::author_from_env`, `merge_file`, `Clone for Reference`.

### notify-debouncer-mini 0.4 → 0.7 (notify 6 → 8)
- API we use is unchanged. Event types moved to `notify-types` (re-exported); there are Windows `ReadDirectoryChangesW` safety fixes; MSRV is 1.77.

### winreg 0.52 → 0.56
- Edition, MSRV and windows-sys bumps, plus serde/`RegValue` changes we don't use. No code changes needed.

### GitHub Actions
- checkout v7, setup-node v7, pnpm/action-setup v6 and tauri-action v1 all moved to the node24 runtime. None of the removed or renamed inputs are ones we use. Details are in commit `5ac8f40`.

## Code review follow-ups

`/code-review high` on the branch found no regressions from the upgrades. These findings were fixed, one commit each:

- **Non-UTF-8 commit text was blanked.** This was existing behaviour that the git2 migration kept. A new `git_text::lossy()` helper decodes the raw bytes (`*_bytes()` accessors) for summary, body, message and author name/email. Latin-1 commits now display as text instead of empty strings, and they are no longer dropped from squash, cherry-pick, revert or stash messages. A regression test covers it.
- **`pull_branch` ignored the configured upstream** (existing bug). Local `main` tracking `origin/master` couldn't be pulled. It now resolves `branch.<name>.merge`, and falls back to the same-named branch when there's no upstream.
- **Detached-HEAD auto stashes were labelled "WIP on HEAD"** (existing bug). They now say "(no branch)", as git does, so they no longer show a fake branch called "HEAD".
- **Real errors are now kept.** Non-UTF-8 HEAD names now report the actual error instead of "HEAD reference has no name".
- **Vite no longer scans `.claude/`.** The dev watcher ignores it, and the dep scan is pinned to `index.html`.
- **Smaller fixes:** corrected the stale OpenSSL comment in `release.yml`, added `*.tsbuildinfo` to `.gitignore`, and fixed the major-upgrade count in this report.
